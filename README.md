# P147 星空羅盤｜Sky Compass

V0.1 是純前端的互動星圖。手機指向使用絕對方向感測資料，手動星圖支援滑鼠、觸控與鍵盤。定位僅在按下「使用我的位置」時要求，定位及感測資料在瀏覽器內處理。

## 在本機開啟

在本資料夾執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000/`。星表由 HTTP 載入。行動裝置測試請使用 HTTPS 網址。

## 部署到 GitHub Pages

把本資料夾內的檔案（含 `.nojekyll`）上傳至 P147 儲存庫根目錄。在 Settings → Pages 選擇 Deploy from a branch，再選部署分支及 /(root)。開啟 Pages 提供的 HTTPS 網址，分別測試手動、定位及手機指向。網站使用相對路徑，可部署在 `/P147/`。

## 資料與精度

- 星表及星座圖形來自 [d3-celestial](https://github.com/ofrohn/d3-celestial/tree/master/data)，授權見 data/LICENSE。包含 5,044 筆星點及 88 星座（巨蛇座的分離部分各有一筆圖形）。
- 以星表赤經、赤緯與地方恆星時換算幾何方位角與仰角。此版未納入歲差、自行、大氣折射、地形遮蔽或光害。星點僅顯示於幾何地平線上方。
- 方位校準的正值代表順時針修正。手機感測器及磁偏角會影響準確度。
- 準星提示依附近亮星和星座標籤的角距計算。未實作 IAU 星座邊界查詢。
- 此版無登入、資料庫、服務端設定或集中使用分析，尚未執行完整 SBI-P-SDS v3.7 部署驗收。

## V0.2 相機觀星

1. 在手機瀏覽器開啟 HTTPS 網址，按「相機觀星」並允許後鏡頭及方向感測。請確認觀測地點，或按「使用我的位置」。
2. 從「校正天體」選擇此刻看得到、且能確認身分的月亮或亮星。把它對準畫面中央，按「以此校正」。
3. 轉動手機查看附近天體。若中間能對準、邊緣的標記偏得較多，可以微調「鏡頭視角」。滑桿代表原始鏡頭影像長邊視角，預設估計為 70°。
4. 按「重設相機校正」可再校正。切換至手動星圖或手機指向會關閉相機。切換觀測地點也會清除對準修正。

影像即時顯示於瀏覽器內，不錄影、不上傳、不使用 AI。手機若只能提供相對方向，先校正才會顯示標記。沒有可用方向資料時，可用手動星圖。單點校正會修正鏡頭指向，仍受感測漂移、鏡頭視角與光學畸變影響。月亮採用 [Paul Schlyter 的近似模型](https://stjarnhimlen.se/comp/ppcomp.html)及簡化地表視差修正。
